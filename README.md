# 建築マニア！REAL 3D v42

## GitHub Pagesで公開
1. このフォルダ内の `index.html` と `README.md` をGitHubリポジトリのルートへアップロードします。
2. GitHubの **Settings → Pages** を開きます。
3. **Deploy from a branch**、`main`、`/(root)` を選んで保存します。

## v42の動作安定化
- iPadなどモバイル端末の描画解像度を抑えてGPU負荷を軽減
- 影マップを小さくして描画負荷を軽減
- ゲーム中は非表示の住宅プレビューを描画しない
- 命中時のパーティクル数を削減
- 住宅モデル再生成時に古い3Dジオメトリとマテリアルを破棄
- 連続命中時の住宅モデル更新を短時間まとめて処理

Three.jsをCDNから読み込むため、プレイ時はインターネット接続が必要です。iPad / Joy-Conでの実機動作確認は利用者の端末で行ってください。
