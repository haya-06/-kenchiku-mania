# 建築マニア！REAL 3D v50

GitHub Pages用ファイルです。

## 更新内容
- Joy-Conのメニュー操作はBボタン（Gamepad API button index 1）のみで開始・再プレイ
- Aボタン、Start/Optionsボタンではコントローラーから開始しない
- 残り時間が0になった後、TIME UP表示を出して約3秒後に結果発表

## 公開方法
リポジトリの `index.html` をこのZIP内の `index.html` に置き換えてコミットしてください。
Three.jsをCDNから読み込むため、プレイ時はインターネット接続が必要です。

※Joy-Conのボタン番号はiPadOS・ブラウザ・接続方法によって異なる場合があります。実機での動作確認は別途必要です。
