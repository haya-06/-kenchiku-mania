# 建築マニア！REAL 3D v43

## GitHub Pagesで公開
1. `index.html` と `README.md` をリポジトリのルートにアップロードします。
2. Settings → Pages → Deploy from a branch → `main` → `/(root)` を選択して保存します。

## v43の変更
- ゲーム中の右上の住宅プレビューを拡大
- 結果画面の完成住宅を拡大
- 結果画面のランキング表示をTOP 5に変更（保存記録はTOP 10のまま）
- v42の変更（通り過ぎた的の減点なし、Joy-Con Bボタンで開始、結果画面コンパクト化）を継承

Three.jsをCDNから読み込むため、プレイにはインターネット接続が必要です。Joy-Con対応はiPadOS/Safariの組み合わせに依存します。
